# 波尔图出租车轨迹数据分析项目
> 数据集：train_100k（ECML/PKDD 2015公开脱敏子集）

## 📋项目简介
本项目针对波尔图出租车轨迹数据集，完成**数据质量评估 + 业务数据分析**，产出分析报告、源代码、答辩PPT、个人总结报告。
- 数据质量评估：完整性、规范性、唯一性、一致性、准确性、时效性、代表性7大维度，共16项质量检查
- 业务分析：出租车热点站台、发车潮汐时空规律、候客停留识别
