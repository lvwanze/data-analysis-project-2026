# 课程小组数据分析项目
> 5人小组数据流水线项目｜课程大作业

## 项目简介
【项目主题，示例：电商用户消费行为数据集分析项目】
本项目按照完整数据流水线完成数据分析，产出两份核心报告：数据质量分析报告、业务数据分析报告；可选实现前端可视化展示页面。项目所有代码、数据集、报告文档、图表均托管在此仓库，保留完整Git提交记录。

## 项目目录结构

├── data/                # 数据文件夹
│   ├── raw/             # 原始数据集（不修改原始文件，用于溯源）
│   └── clean/           # 经过清洗、预处理后的数据集
├── code/                # 分析代码
│   ├── data_quality.ipynb      # 数据质量检测代码，生成质量分析图表
│   └── business_analysis.ipynb # 业务维度数据分析、可视化绘图代码
├── report/              # 项目交付报告
│   ├── img/             # 报告中所有可视化图表图片
│   ├── 数据质量分析报告.docx
│   ├── 数据质量分析报告.pdf
│   ├── 项目数据分析报告.docx
│   └── 项目数据分析报告.pdf
├── web-display/         # 【加分项】前端可视化展示页面
│   ├── index.html
│   ├── style.css
│   └── script.js
├── .gitignore           # git 忽略文件配置
└── README.md            # 项目说明文档

## 作业交付清单（对应老师作业要求）
1. ✅ 数据质量分析报告
文件路径：`report/数据质量分析报告.pdf`
- 包含完整编号图表、图表解释说明，数据质量检测结论。

2. ✅ 项目数据分析报告（业务分析）
文件路径：`report/项目数据分析报告.pdf`
- 基于清洗后的数据集完成业务层面分析，输出业务洞察与结论，配套规范可视化图表。

3. ⭐【加分项】对外展示系统（前端页面）
文件路径：`web-display/index.html`
- 直接打开html文件即可查看数据可视化展示页面。

4. ⭐【加分项】Git版本管理
仓库保留全流程提交记录，小组每位成员都有独立提交记录，可查看每个人的项目贡献。

## 小组五人分工
- 成员1：数据采集、原始数据预处理与清洗
- 成员2：数据质量检测，编写【数据质量分析报告】，生成质量相关图表
- 成员3：业务维度数据分析，可视化绘图，业务指标计算
- 成员4：撰写【项目数据分析报告】，梳理业务结论、撰写文档
- 成员5：前端展示页面开发，仓库维护、文档整理、版本协同

## 环境说明
数据分析使用 Python + Jupyter Notebook
依赖库：pandas, numpy, matplotlib, seaborn

## 如何查看项目
1. 查看报告：进入`report`文件夹，打开PDF文件阅读
2. 查看代码：进入`code`文件夹打开ipynb文件
3. 前端展示：进入`web-display`文件夹，打开index.html

## 版本提交说明
每次修改文件后，使用git提交，提交信息规范示例：
- `【数据预处理】完成原始数据缺失值、重复值检测`
- `【报告】更新图3业务分布图表，补充图注说明`
- `【前端】完成基础页面布局，接入数据可视化
